## The entry

> I'm out of office — this auto-reply is the most productive thing I've done all week.

The joke turns on the auto-reply itself instead of the usual beach,
inbox or limited-email lines: it lands on the first read and still reads
like a message a real person would switch on before going away.

## How it works

`main.py` (pure Python standard library, no network) writes the single
line to `/output/entry.txt` — 84 characters, one line, inside the
competition's 1–160 character gate.

```sh
python3 main.py
cat /output/entry.txt
```
